# وذكر 2.0.0

مشروع Android Native جديد من الصفر، بواجهة Neon Islamic مختلفة فعليًا عن المشروع السابق.

Application ID: `com.saleh.wadhkur`

## البناء في Termux
بعد فك الضغط داخل مجلد المشروع:

```bash
gradle wrapper --gradle-version 8.7
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`
